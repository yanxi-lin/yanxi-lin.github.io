# Design notes

Audience: researchers and prospective collaborators in AI hardware. The primary job is to make Yanxi's background and published research easy to read.

Palette: paper `#f6f9fc`, ink `#172d46`, body `#3d5066`, blue `#245789`, line `#dbe4ed`, panel `#edf3fa`.

Typography: Newsreader for the name and section headings; Source Sans 3 for reading and navigation. Local font files avoid third-party font requests.

Layout: a restrained introduction with an original PE-array illustration, followed by left-aligned sections. Desktop uses section labels beside their content; mobile stacks them. No fabricated portrait, metrics, institutional logo, contact address, or private project links.

```
YL                                  navigation
Name + introduction                 PE array
Research interests                  topic descriptions
Publications                        DPAM + citation
Education                           degree dates
Experience & projects               internship + PE work
```

Review: a serif name alone would be generic, so the technical subject is expressed by the single original PE-array illustration. Avoided dashboard cards, animation, and decorative statistics. The manuscript and final program differ in title; this is recorded in README rather than silently inventing publication metadata.
